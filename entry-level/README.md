# Entry Level

This roadmap is designed for beginners who want to start their journey in cybersecurity from the ground up. The Entry phase focuses on building a strong foundation in the core topics needed to understand how systems, networks, and security tools work. During this stage, you will learn the basics of networking, Linux, Windows, scripting, Python, and cybersecurity principles before moving into more advanced areas such as cryptography, offensive security, and practical security exercises.

The goal of this phase is not only to study theory, but also to build hands-on skills through labs, exercises, and real-world scenarios. By the end of this stage, you should be comfortable with the command line, understand how systems communicate, know the basic security concepts, and be ready to explore deeper areas in cybersecurity with confidence.
